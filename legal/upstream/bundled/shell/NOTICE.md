# PACKIT Windows shell extension

Original PACKIT code, GPL-3.0-only. Source: windows-shell/src/lib.rs and src-tauri/src/naming.rs in this repository, built with windows-shell/Cargo.lock. Full GPLv3 text is in COPYING-GPL-3.0.txt. The small DLL only supplies IExplorerCommand titles and typed launch handoff; no archive code or password state is loaded into Explorer. Microsoft windows-rs and the existing serde_json/unicode-normalization dependencies retain their permissive licenses; final source/notice completeness must be audited before distribution.
