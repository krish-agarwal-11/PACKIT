# Native archive test fixtures

- lzma.7z and lzma2.7z: generated with official 7-Zip 26.05 from original PACKIT text and the Unicode path nested/café.txt.
- compressed-rar4.rar: one compressed member (testdir/test.txt) from libarchive v3.8.11 test_read_format_rar_compress_normal.rar.uu, retaining the original main, file and end records. Other files and the symbolic link were removed.
- compressed-rar5.rar: decoded without edits from libarchive v3.8.11 test_read_format_rar5_compressed.rar.uu.

RAR source: https://github.com/libarchive/libarchive/tree/v3.8.11/libarchive/test. The upstream distribution notice is included as COPYING-libarchive.txt. Fixtures are development data and are not installer resources.

unsupported-bzip2.7z and encrypted-header.7z are generated negative fixtures from original text, using official 7-Zip 26.05. The latter uses the fixture-only password "fixture-only".

encrypted-aes.zip and encrypted-zipcrypto.zip: original text, created with 7-Zip 26.05 using fixture-only password "fixture-only". cancellation-stream.7z contains one MiB of zero bytes solely for exercising termination of a decoder blocked on its output pipe. The volume fixtures come from the libarchive v3.8.11 test sets test_rar_multivolume_single_file.partN.rar.uu and test_read_format_rar5_multiarchive.partNN.rar.uu; the three sample.7z.NNN parts are a byte split of lzma2.7z. Their contents are never executed.

python-pax.tar and python-pax.tar.gz: original payload generated by `python src-tauri/tests/fixtures/generate_pax.py`, using Python tarfile's default POSIX PAX format. Includes global metadata, local fractional timestamps, nested directories, long paths and Unicode. GZIP timestamp is fixed for reproducibility.

iso9660.iso, joliet.iso and rockridge.iso: real small single-volume images generated by `generate_iso.py` with development-only pycdlib 1.16.0 (LGPL-2.1). Original PACKIT payload, nested and empty directories, Unicode Joliet/Rock Ridge filenames. The generator is not part of the application and requires pycdlib only when regenerating fixtures. No executable payloads.

udf260.iso is a real small physical-partition UDF image generated by development-only pycdlib 1.16.0 using generate_udf.py, containing original PACKIT text, a Unicode nested file, an empty file and an empty directory. Although the writer API calls its output UDF 2.60, the actual domain suffix specifies minimum read revision 1.02; PACKIT reports the on-disc minimum, not universal 2.60 support. The separate ignored supplied-image test reads the user's external ISO without modifying it and extracts only one small selected file into a temporary test directory. That user's large image is not redistributed as a fixture.
